# Find Your Duo 🎮🕹️

Aplicação mobile e desktop para se cadastrar e procurar amigos para jogar o mesmo jogo que você quer.

## Stacks

-   React
-   Radix
-   Phosphor React
-   Eslint
-   Tailwindcss
-   React Native
-   Node
-   Prisma
-   Express
-   TypeScript

## Layout e preview

[figma](https://www.figma.com/community/file/1150897317533332617/nlw-esports)
[Instalando Expo Go](https://efficient-sloth-d85.notion.site/Instalando-Expo-9b0abcb12bd548278e042d00fbde67f2)

## Como rodar os projetos localmente

**mobile**

```bash
cd ./find-your-duo/mobile

npx expo start
```

**server e web**

```bash
cd ./find-your-duo/web

npm run dev

cd ./find-your-duo/server

npm run dev
```
